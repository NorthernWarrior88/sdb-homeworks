### Задание 2

1. Установите поддержку **LUKS**.
2. Создайте небольшой раздел, например, 100 Мб.
3. Зашифруйте созданный раздел с помощью LUKS.

### Решение

1.Устанавливаем gparted cryptsetup (LUKS)

      apt install gparted cryptsetup
      
![изображение](https://github.com/user-attachments/assets/db99f4bb-54ec-455f-9fbd-0f2aff1a7904)



2.Создал раздел 100мб (sda3)

![изображение](https://github.com/user-attachments/assets/9fe6ae01-dfd2-4bbe-8390-1622e99b2495)

3. Зашифруйте созданный раздел с помощью LUKS.
Подготавливаем раздел (тип luks2)

         sudo cryptsetup -y -v --type luks2 luksFormat /dev/sda3

![изображение](https://github.com/user-attachments/assets/48047844-dc99-40a2-8656-e8241cfba412)


Открываем устройство /dev/sdb и задаем ему имя cryptodisk

      sudo cryptsetup luksOpen /dev/sdb cryptodisk


![изображение](https://github.com/user-attachments/assets/6d3f8923-a8a9-4ba4-b295-e014a61669b7)

![изображение](https://github.com/user-attachments/assets/800afaba-b79e-4581-bbf4-e7664e586af9)


Форматируем раздел

      sudo dd if=/dev/zero of=/dev/mapper/cryptodisk

      sudo mkfs.ext4 /dev/mapper/cryptodisk

![изображение](https://github.com/user-attachments/assets/ff2a966d-2bcc-4416-8d28-598f5793fd82)



Монтируем открытый раздел

      mkdir .secret

      sudo mount /dev/mapper/cryptodisk .secret/

![изображение](https://github.com/user-attachments/assets/efe03cb4-e75c-4ba6-82bc-ff94be5af4e1)


Завершение работы

      sudo umount .secret

      sudo cryptsetup luksClose cryptodisk
